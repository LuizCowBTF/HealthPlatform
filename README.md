## 📖 Visão Geral

💼 Plataforma SAAS composta por dois sistemas integrados:

<br>

### 🏥 HealthCRM/SaaS

#### Sistema de gestão de vendas de planos de saúde com:

- Cadastro de propostas e clientes

- Gestão de corretores/vendedores

- Funil de vendas e acompanhamento

- Análise técnica de documentos

- Painéis de performance comercial

<br>

### 💰 FinancialSystem

#### Sistema de gestão financeira e comissionamento com:

- Cálculo automático de comissões (1ª, 2ª, 3ª parcela)

- Tabelas de margens editáveis por operadora/categoria

- Gestão de descontos e taxas

- Extratos PDF e conciliação bancária

- Painéis financeiros e relatórios

## 🎯 Visão do Projeto

A **Health Platform** é um ecossistema completo para gestão de vendas de planos de saúde, combinando **CRM tradicional** com **Inteligência Artificial** para automatizar e potencializar o processo comercial.


### 🚀 Características Principais

✅ **Dashboard Profissional** - Interface moderna com gráficos e KPIs  
✅ **CRM Completo** - Gestão de leads, clientes e corretores  
✅ **Sistema Financeiro** - Apuração financeira e comissões  
✅ **Integração WhatsApp** - Comunicação automatizada  
✅ **IA Integrada** - Análise de dados e automações  
✅ **API RESTful** - FastAPI com documentação automática  
✅ **Responsivo** - Funciona em desktop e mobile  
✅ **Multi-usuário** - Hierarquias e permissões

### 📊 Funcionalidades Detalhadas

#### 🏥 HealthCRM/SaaS 

| Módulo |	Status	| Descrição |
| :----- | :-------: | :---------: |
| Gestão de Propostas |	✅	| Cadastro completo com validação de dados |
| Controle de Corretores |	✅ |	Multi-tenant com isolamento de dados |
| Funil de Vendas |	✅ |	Acompanhamento de status e conversões |
| Documentos Digitais |	🔄	| Upload e análise técnica de contratos |
| Painéis Comerciais |	✅ |	KPIs e métricas de performance |
| Integração Financeira |	✅ |	Webhooks para comissionamento automático |

<br>

#### 💰 FinancialSystem

| Módulo |	Status |	Descrição |
| :----- | :-----: | :--------: |
| Cálculo de Comissões |	✅ |	Parcelas P1, P2, P3 com margens configuráveis |
| Tabelas de Margens |	✅ |	Editáveis por operadora/categoria/corretor |
| Descontos Automáticos |	✅	| Configuráveis por operadora (ex: Porto Seguro 2.38%) |
| Extratos PDF |	✅	| Geração e armazenamento de extratos |
| Conciliação Bancária |	🔄 |	Status de pagamentos e repasses |
| APIs de Integração |	✅	| Webhooks do HealthCRM em tempo real |
